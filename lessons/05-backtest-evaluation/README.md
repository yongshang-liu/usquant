# 第五课：读懂收益、回撤、成本和比较实验

## 学习目标

把“引擎跑完”与“策略有效”分开；知道收益、现金、未实现盈亏、最大回撤、费用与基准是什么；从真实 LEAN 输出复核数字。先修前四课。代码：[main.py](main.py)、[分析脚本](../../scripts/analyze_results.py)。

## 固定对照实验

策略固定：首次有效 SPY 行情请求 20% 仓位。资金 2,500 美元、时间和其他设置相同，分别测试 5 bps 与 20 bps 常数滑点。参数名 cost-bps 仅为实验入口，实际控制的是滑点；手续费仍由券商模型单独计算，不要重复或漏计。

```sh
# 情景 A：5 基点滑点。
python3 scripts/run_lean.py evaluation --parameter cost-bps=5
# 情景 B：20 基点滑点；运行后保留独立目录。
python3 scripts/run_lean.py evaluation --parameter cost-bps=20
# 把下面路径替换为刚刚打印目录中的主结果 JSON，不能用 summary 文件。
python3 scripts/analyze_results.py results/你的运行目录/USQuant-LEAN-evaluation.json
```

1 bps=0.01%，所以 20 bps=0.2%。不是每笔固定收取 20 美元。ConstantSlippageModel 是简化模型，不会自动还原真实盘口、冲击成本和排队。

## 按输出复核

主 JSON 包含 charts、orders、statistics 等。Strategy Equity/Equity 的数组若是 [time,open,high,low,close]，应读取最后一项 close，而不是把 open 当成最终权益。普通点可能是 [time,value]。分析脚本明确处理两种数组结构。

采样收益=末值/首值−1。最大回撤是逐时点相对“截至当时已观察峰值”的最大损失，不能用整个样本的未来峰值计算早期回撤。日内极值可能不在采样点中，因此脚本的 sampled_max_drawdown 可能不同于引擎统计。

报告保留引擎原统计与重算值，两者不一致时先检查起止点、采样频率、现金流和费用口径，而不是挑一个更好看的值。

## 基准与评价

SPY 基准在本课中接近满暴露买入持有，而策略只投约 20%、其余留现金。直接比较原始收益不是风险调整结论，应同时解释敞口、波动和资金利用程度。

五天样例可能打印很高的年化收益或夏普，但数据量不足以作长期推断。本课程不以这些数值挑策略，不声称做了多年样本外测试。

生产研究要预先划分开发、验证、最终测试，进行走样本外或滚动评估；保留每次尝试记录。若多次试参后选择最优结果，还要考虑数据窥探和多重检验。覆盖不同市场状态，并使用与策略相符的基准和费用模型。

## 练习与参考答案

1. 100 → 80 → 120 的资金曲线：总收益 20%，最大采样回撤 20%；后来上涨不能抹去早期回撤。
2. 两个情景为什么股数可能不同？滑点会影响购买力和目标数量计算。若数量不同，费用差异不仅来自单纯的成交价变化。
3. 最终权益增加 6 美元是不是已实现利润？未必。若持仓未平，部分属于按末价计的未实现盈亏。
4. 净收益较低是否就应降低费用假设？不应。费用要依据可用交易条件和保守假设设定，而不是为了让策略盈利。
5. 为什么不把五天人为分成三天训练、一天验证、一天测试就称为有效？名称不能补足样本量和独立性；这里只能演示流程，真正验证需要足够时间与不同环境。

## 排错与验收

找不到 charts：通常选择了 summary 或配置文件。找不到 Equity：先检查实际版本输出结构，不静默用零代替。空曲线应报错。完成标准是保存两次独立结果和 evaluation.json，能解释成本变化与统计口径；不是必须收益为正。下一课：[订单与券商模拟](../06-paper-orders/README.md)。
